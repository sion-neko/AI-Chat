# 文字起こしAPIのお願い（下書き）

おばけ探偵事務所（手元で動かす横断検索AIチャット）で、会議の録音を文字起こしして、あとから探せるようにしたいと考えています。
会議には秘密の話が含まれるため、外部のサービスではなく、社内で文字起こしを動かしたいです。
今の社内LLMと同じように、文字起こしのAPIを立てていただけないでしょうか。

## ほしいもの

- OpenAI 互換の文字起こしAPI（`POST /v1/audio/transcriptions`）
  - 例: vLLM・faster-whisper-server・whisper.cpp のサーバーなど
- 日本語に強いモデル
  - 例: kotoba-whisper（日本語向けに軽くした Whisper）、または Whisper large-v3
- 返り値に、区切りごとの時刻（`response_format=verbose_json` の segments）が付くこと

## 使い方の見込み

- 1回あたり最大1時間ほどの会議の音声を、10分ずつ区切って送ります
- 使う人は福岡のインフラメンバー（数人〜十数人）を想定しています
- GPUがあれば1時間の会議が数分で終わる見込みです（CPUだと数十分〜1時間）

## 手元のツール側

- `.env` に送り先（URL・モデル名・APIキー）を書くだけで切り替えられるようにします
- 音声は文字起こしが済んだら手元から消します

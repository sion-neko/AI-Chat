# 0003 ファイルサーバー（Synology）をつなぐ

- 日付: 2026-10-28
- 状態: 採用（実装はまだ）

## やりたいこと

Synology の NAS にある資料（Excel・Word・PDF・テキスト・設定・ログ・画像など）を、検索ソースの1つとして所員に調べさせる。
「VPNの手順書どこ？」「〇〇の設定値は？」に、ほかのソース（Zulip・GitLab など）とまたいで答えられるようにする。

## 前提

- ふだんは Windows の共有フォルダ（SMB、`\\nas\共有`）でつないでいる
- 探すのはファイル名で当たりを付ければ足りる（中身での検索は今は要らない）
- 古い形式（.xls・.doc）はほとんどない

## 決めたこと

### つなぎ方：アプリが SMB で直接つなぐ

- Python のライブラリ（smbprotocol の smbclient）で、`.env` に書いた自分のアカウントでつなぐ
  - `NAS_HOST` / `NAS_USER` / `NAS_PASSWORD`（ドメインがあれば `NAS_DOMAIN`）
- 自分の権限で見られるファイルだけを触る（SPEC の方針どおり）。書き込みはしない
- 共有フォルダの一覧を取り、GitHub のリポジトリと同じく、調べる共有フォルダ（とその下のフォルダ）を質問ごとに選べるようにする
- 接続確認の画面で、つながるかと、見られる共有フォルダの数を出す

### ファイル名の索引を手元に持つ

- SMB にはサーバー側で探す仕組みがなく、毎回フォルダをたどると大きな共有では遅すぎる
- 選んだ共有フォルダの、パス・名前・更新日・大きさだけを集めて SQLite に入れる（名前とパスは FTS5 の trigram で部分一致）
- 中身は入れないので軽い。集める処理は裏で走らせ（app/jobs.py）、進み具合を画面に出す
- 集め直すのは、一定の間隔（既定は1日1回）と、画面の「索引を作り直す」ボタン。更新日で変わったフォルダだけをたどる工夫は後回し

### 所員の道具

- `find_files(query, since?, folder?)`: 名前・パスで探す。更新日で絞れる。新しい順にパスと更新日を返す
- `read_file(path)`: ファイルを開いて文字にして返す。長いものは先頭から決まった量（例: 2万文字）まで
  - Word（.docx）・Excel（.xlsx、シートごと）・PowerPoint（.pptx）・PDF・テキスト・ログ・CSV・設定ファイル
  - 画像は、画像を読めるモデルのときだけ、今の view_image と同じ形で読む
  - 古い形式（.xls・.doc）や読めない形式は、「開けない」と返す（名前で見つけたことは伝わる）
- 文字にするライブラリは、形式ごとの軽いもの（python-docx・openpyxl・python-pptx・pypdf）を使う

### 出典

- `\\nas\共有\手順書\VPN.docx` のようなパス（Windows の形）にする。ブラウザからは開けないので、出典のカードに「パスをコピー」を付け、エクスプローラーに貼ってもらう
- 出典の照合（app/links.py）は今は URL だけを見ているので、このパスも照合の対象にする

## 考えたほかの案

- **File Station の Web API**: 自分のアカウントで使え、出典をブラウザで開ける URL にできる。ただ、ふだん File Station を使っていないので DSM の Web に入れるか分からず、API の検索も名前だけで、SMB と比べた得がない
- **共有フォルダを Docker のボリュームにマウント（CIFS）**: ライブラリは増えないが、環境ごとにマウントの設定が要り、つながらないときの原因が画面から分かりにくい
- **Synology の Universal Search（中身の全文検索）**: 中身で探せるが、公開されていない API なので DSM の更新で壊れるおそれがある
- **中身の索引を手元に作る**: 名前で分からないものも探せるが、重く、今は要らない。必要になったら、選んだフォルダだけ後から足せる

## 割り切ったこと

- 古い形式（.xls・.doc）は読まない（LibreOffice を入れるとイメージが数百MB大きくなるため）
- 索引は名前・パス・更新日だけ。中身での検索はしない
- 索引は手元の DB にあるので、NAS 側で消したファイルが次に集め直すまで残ることがある（開こうとして見つからなければ、そう伝える）

## 確かめ方

- 実データには触れず、テスト用の偽の SMB サーバー（または smbclient を差し替えた偽物）で、索引・検索・読み取り・権限のないフォルダの扱いを確かめる
